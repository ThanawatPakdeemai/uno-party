# UNO Party Online 🎉

เว็บเกมการ์ดแนว UNO เล่นหลายคนแบบ realtime ผ่านเบราว์เซอร์ รองรับ 2–8 คน และมือถือ

## เริ่มใช้งาน

ต้องติดตั้ง Bun (https://bun.sh) จากนั้น:

```bash
bun install
bun run dev
```

เปิด http://localhost:3001 แล้วสร้างห้อง แชร์ลิงก์หรือ QR Code ให้เพื่อนเข้าร่วม

## เล่นข้ามเครื่อง / ออนไลน์

- ใน Wi-Fi เดียวกัน ให้ใช้ IP เครื่องที่รันเซิร์ฟเวอร์ เช่น `http://192.168.1.10:3001`
- สำหรับเล่นผ่านอินเทอร์เน็ต ให้ deploy เซิร์ฟเวอร์ Bun ไปยังโฮสต์ที่รองรับ WebSocket และ HTTPS เช่น VPS หรือแพลตฟอร์มที่รองรับ Bun/WebSocket และตั้งค่าโดเมน HTTPS
- อย่าส่งลิงก์ localhost ให้เพื่อนต่างเครื่อง เพราะ localhost ชี้ไปที่เครื่องของแต่ละคน

## กติกาเวอร์ชันนี้

แจกคนละ 7 ใบ วางตามสีหรือตัวเลข/สัญลักษณ์; Skip ข้ามคนถัดไป; Reverse กลับทิศ (เล่น 2 คนทำหน้าที่เหมือน Skip); +2/+4 ให้คนถัดไปจั่วและเสียตา; Wild เปลี่ยนสี; +4 ใช้ได้เมื่อไม่มีไพ่สีปัจจุบัน; เมื่อจั่ว 1 ใบ สามารถลงไพ่ที่เข้ากันได้หรือกดผ่าน; เมื่อเหลือไพ่ 1 ใบ กด UNO หรือเพื่อนจับให้จั่ว 2 ใบ

**หมายเหตุ:** เป็นกติกาแบบ simplified house rules ไม่ใช่การจำลองกฎการแข่งขันอย่างเป็นทางการทั้งหมด ไม่มีการ stack +2/+4 และไม่ได้ตรวจการท้าทาย +4

## ข้อจำกัดของต้นแบบ

ข้อมูลห้องเก็บในหน่วยความจำ (restart เซิร์ฟเวอร์แล้วห้องหาย) และผู้เล่น reconnect ได้ใน browser tab เดิมผ่าน sessionStorage; ถ้าต้องการใช้งาน production จริงควรเพิ่ม Redis/DB, token authentication, rate limiting, durable rooms และ automated tests. เจ้าของห้องแก้ชื่อ/รหัสได้ก่อนเริ่มเกมเท่านั้น และลบห้องได้ทุกเวลา


## TypeScript / Vercel

ไฟล์นี้รวม tsconfig.json และ @types/qrcode เพื่อแก้ TS2550 และ TS7016. ระบบ Multiplayer เก็บสถานะในหน่วยความจำและใช้ WebSocket ผ่าน Bun. การ build ผ่านบน Vercel ไม่ได้รับประกันว่า state/WebSocket จะทำงานแบบ production; ควรทดสอบจริงหรือใช้ backend ที่รองรับการเชื่อมต่อถาวรและ shared persistence.
